# Contributing

This project is experimental. Please open an issue describing the problem before making a large change.

1. Fork the repository and create a branch.
2. Use Python 3.12 and install requirements-dev.txt in a virtual environment.
3. Run `python -m unittest discover -s tests -v`.
4. Include a synthetic reproduction fixture and before/after behavior for PDF editing changes.
5. Submit a pull request explaining the change and validation.

Do not commit user documents, uploads, credentials, virtual environments, or build output. Contributions are under the repository AGPL-3.0 license.
