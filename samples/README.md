# PDF Studio sample files

These files are fictional demo assets for testing PDF Studio. They contain no personal data or real company records.

## Files

- `sample-edit-text-and-images.pdf`: two-page synthetic document with selectable text, multi-column rows, and separate raster images. Use it to test text edits and image replacement.
- `sample-combine-second-file.pdf`: one-page synthetic PDF for Combine, page rotation, deletion, and reordering.
- `demo-logo.png`: fictional logo embedded in the editing sample.
- `demo-replacement-logo.png`: alternate logo for Replace Image tests.
- `demo-illustration.png`: separate raster illustration embedded on page two.

The PDFs contain selectable text rather than scanned pages. Exact text-edit fidelity may vary with fonts and PDF structure. These files are intended for tests and demos.
